# 集客开通基层监督员权限配置

基层监督员名单已经内置在 `lineProjectData/config.js` 的 `SUPERVISOR_ROSTER` 中，来源为“区县基层监督员明细.xlsx”。

部署 `lineProjectData` 和 `userManagement` 云函数后，用系统管理员进入“集客线路项目工作台”，点击“同步基层监督员”即可完成：

系统管理员仅由 `users.role = system_admin` 授权。部署前请在云数据库为正式管理员账号明确设置该角色；姓名或网格通账号不会再自动提升权限。

1. 按区县新增或更新 `feedback_routes.supervisor`；
2. 保留每个区县原有的 `districtManager` 配置；
3. 对已注册且网格通账号匹配的用户，授予 `district_supervisor`、`line_project` 工作台及本区县数据范围；
4. 未注册的监督员在路由同步后首次完善资料时，会根据网格通账号自动获得上述权限。

区县经理不在本次附件中。若某区县尚未配置 `districtManager`，该区县可以查看数据，但问题反馈在双审批人完整配置前不能提交。
